Fix IP problem for Xserver. Cant find screen - ZORIN 18 WSL


OPEN POWERSHELL AND TYPE: ipconfig


NOTE - Importent to look for ip. Last lines in terminal are IP-numbers for WSL via POWERSHELL.


SAVE IP FOR LATER USE LIKE THIS FROM POWERSHELL: 172.30.16.1


NOW GO BACK TO DEEPIN Terminal and paste this.

sudo apt install systemd-resolved

sudo systemctl unmask systemd-resolved.service
sudo systemctl enable systemd-resolved.service
sudo ls -l /etc/resolv.conf
sudo mv /etc/resolv.conf /tmp/resolv.conf.bak
sudo nano /etc/resolv.conf

nameserver 172.30.16.1 <-- put your ip here from powershell and add nameserver like this.

sudo chattr +i /etc/resolv.conf
sudo systemctl restart systemd-resolved
sudo cat /etc/resolv.conf

IF YOU TYPE WRONG IP ADRESS ALL WILL STOP WORKING - NO STRESS.

DONE - Lot of problem fixed FOR ZORIN OS 18.1 and BUDGIE DESKTOP =]

Start BUDGIE Desktop via this lines - ZORIN OS 18 - BUDGIE DESKTOP


FIRST START X410 XSERVER THEN YOU START ZORIN OS 18 VIA TERMINAL / CONSOLE / BASH


Paste in terminal: export DISPLAY=$(cat /etc/resolv.conf | grep nameserver | awk '{print $2; exit;}'):0.0

Paste in terminal: . ~/.bash_Debian_desktop

Paste in terminal: xhost +

Paste in terminal to start desktop: budgie-desktop 


JUST WAIT IT TAKE SOME TIME TO START BUDGIE VIA ZORIN OS.
