Fix IP problem for X410 or other Xservers. Cant find screen 0:0 - AnduinOS

OPEN POWERSHELL AND TYPE: ipconfig

YOU WILL SEE SOMETHING LIKE THIS - THAT IP IS WHAT WE WANT SAVE IT.

Ethernet adapter vEthernet (WSL (Hyper-V firewall)):

   Connection-specific DNS Suffix  . :
   Link-local IPv6 Address . . . . . : fe80::c22d:775:81d4:984
   IPv4 Address. . . . . . . . . . . : 192.168.144.1

NOTE - Importent to look for ip. Last lines in terminal are IP-numbers for WSL via POWERSHELL.

SAVE IP FOR LATER USE LIKE THIS FROM POWERSHELL: 192.168.144.1

----------------------------------

NOW GO BACK TO AnduinOS Terminal and paste this.

NOTE - IF YOU SE SOME ERRORS ALL WORKS ANY WAY =)

sudo apt install systemd-resolved

sudo systemctl unmask systemd-resolved.service
sudo systemctl enable systemd-resolved.service
sudo ls -l /etc/resolv.conf
sudo mv /etc/resolv.conf /tmp/resolv.conf.bak
sudo nano /etc/resolv.conf

nameserver 192.168.144.1 <-- put your ip here from powershell and add nameserver like this.

sudo chattr +i /etc/resolv.conf
sudo systemctl restart systemd-resolved
sudo cat /etc/resolv.conf

NOTE - IF YOU TYPE WRONG IP ADRESS ALL WILL STOP WORKING - NO STRESS.

DONE - Lot of problem fixed FOR AnduinOS and KDE
